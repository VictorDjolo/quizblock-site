QuizBlock is gone. Was it on purpose?

If you removed it in a weak moment, that’s exactly the moment it was there for. It takes a minute to add back, and your sites and settings return if settings sync was on.

If you meant it, thank you for trying it. A few things that might help without it:

  • Name the pull. Before opening a site, say what you’re there for. It’s surprisingly hard to scroll without a reason once you’ve said one out loud.
  • Move the door. Log out of the sites that pull hardest, so getting in takes a deliberate step.
  • Keep what you learned. Spaced repetition works anywhere: a few minutes a day with flashcards keeps the countries and facts you collected.

If something didn’t work for you, I’d really like to know. One line is plenty: quizblockapp@gmail.com

This page is a plain web page the browser opens when QuizBlock is removed. It runs no scripts and records nothing. QuizBlock’s data was stored only in your browser, and removing the extension deleted it.
